Calculadora Básica de IMC
Una calculadora sencilla que permite calcular el Índice de Masa Corporal (IMC) de una persona a partir de su peso y altura. Está hecha con HTML, CSS y JavaScript.

Características
Interfaz simple y fácil de usar.

Permite al usuario ingresar su peso y altura.

Calcula automáticamente el IMC al hacer clic en un botón.

Muestra la clasificación del IMC basada en los valores calculados (bajo peso, normal, sobrepeso, obesidad).

Tecnologías
HTML: Estructura básica de la página web.

CSS: Estilos y diseño de la página para hacerla visualmente atractiva.

JavaScript: Lógica para calcular el IMC y mostrar los resultados dinámicamente.
